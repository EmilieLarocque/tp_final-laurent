Ce portfolio (bureau Windows interactif)

Site web · Août 2026

Aperçu

🖥️

Ce site portfolio recrée l'expérience d'un bureau Windows directement dans le navigateur : fenêtres, barre des tâches, écran de verrouillage, widgets météo et calendrier, le tout construit à la main en HTML, CSS et JavaScript, avec Tailwind pour les mises en page ponctuelles. C'est aussi une progressive web app (PWA) installable, avec Service Worker et prise en charge du mode hors-ligne.

Technologies utilisées

HTML CSS JavaScript Tailwind CSS PWA
